# 선관위 제출서류 HWPX 템플릿 (Phase 1)

`RAG/1. 제9회 지방선거 정치자금 회계실무_작성예시.hwpx`(통합본, 11섹션)에서
Phase 1 핵심 서식만 **개별 `.hwpx`로 분리**하고, 채울 값을 **`{{토큰}}`으로 치환**한 템플릿.

> 관련 기획: `docs/01-plan/features/hwpx-form-generator.plan.md` (부록 A)

## 포맷 전용(배경 제거)

작성예시 책자의 **페이지 배경 이미지·색을 제거**하고 서식 포맷(표·텍스트 레이아웃)만 남김.

- secPr의 `<masterPage>` 참조 삭제 → 전면 배경 이미지(마스터페이지) 미적용
- secPr의 `<pageBorderFill>` → `borderFillIDRef="0"` → 페이지 색/테두리 제거
- 미참조 마스터페이지 21개 + 배경 이미지 16개 패키지에서 제거(헤더 참조 이미지 5개만 유지)
- 결과: 파일당 약 **208KB**(원본 분리본 1.07MB 대비 5배 슬림), 흰 바탕·검정 선/글자

## 생성 방식 (런타임)

템플릿 `.hwpx`(ZIP) 안 `Contents/section0.xml`의 `{{토큰}}` 문자열을
입력값으로 치환 후 재압축하면 한글에서 바로 열리는 결과 문서가 된다.

- ZIP 라이브러리: JSZip(Node) — `mimetype`은 **첫 엔트리·무압축(STORED)** 유지 필수
- 치환 전 입력값 **XML escape**(`& < > " '`) 필수
- 구조(문단·표·스타일·secPr)는 건드리지 않음 → 공식 레이아웃·쪽수 보존

## 토큰 추가/새 서식 템플릿화 규칙

1. 통합본에서 서식 단위로 분리(서식 본문 문단 + 해당 섹션 secPr 이식, 목차/타서식 제외)
2. 채울 값(예: `○○○`, 예시 전화·계좌·주소)을 **한 `<hp:t>` 노드** 단위로 `{{토큰}}` 치환
3. 토큰은 한 줄·연속 문자열(서식 변화 없이) → 단일 텍스트 노드 보존
4. 표 셀 너비를 넘기는 긴 값은 쪽수 드리프트 주의(셀 폭 확보)

## ⚠️ 검수 필요

자동 분할·토큰화는 XML 구조 검증·생성 시뮬레이션까지 통과했으나,
**한글(Hancom Office)에서 실제로 열어 레이아웃·토큰 위치를 눈으로 확인**할 것.
미세 어긋남 발견 시 해당 서식만 한글에서 재저장 후 토큰 재적용 권장.

## 미토큰화 항목 (의도적)

- 신고인란의 대체 서명자(선거연락소장·후원회 대표자 등)는 `○○○` 유지 — 공식 양식 보일러플레이트, 사용자가 불필요 항목 삭제
- 주민등록번호·생년월일·날짜(`년 월 일`)는 빈칸 유지
- 문서번호는 빈칸 유지
