## 1. 배경 및 범위

### 1.1 선행 계획과의 관계
- [[burden-cost-claim]](2026-04)은 부담비용 **도메인 전반**(판별 로직·wizard·보전 페이지 탭·서식7 **Excel** 출력)을 계획했고, expense-types 부담비용 카테고리/`ReimbursementStatus`/wizard 카드까지는 완료(✅). 그러나 **서식 7 생성은 미구현**이며 당시엔 `lib/excel-template/` Excel 출력으로 계획됨.
- 본 계획은 그 미구현 항목(서식 7)을, 2026-05~06에 구축된 **성숙한 HWPX 폼-채움 시스템**으로 대체 구현한다. `reimbursement-claim-form`(광의) → `reimbursement-claim-hwpx`(HWPX 구현)와 동일한 분리 패턴.
- 본 계획 **범위 밖**(선행 계획 또는 후속): 보전 페이지 부담비용 탭, 부담비용 자동 필터/집계, 활동보조인 명세서 자동생성, D-day 알림.

### 1.2 양식 구조 (템플릿 추출 결과)
| 영역 | 내용 | 데이터 소스 |
|------|------|------------|
| 머리 | 1.선거명 · 2.소속정당명 · 3.후보자명 | organ/입력 |
| 4. 작성·제출수량 표 | 점자공보·점자공약서·저장매체(개) × [작성·제출 부수(A)/1부당매수(B)/총매수(C)] × [작성·발송 …] | **수기 입력**(물리수량, DB에 없음) |

## 2. 핵심 설계 결정 (Plan 단계 확정)

### 2.1 토큰-채움(순수) vs 데이터-채움(dataFill)
- **결정: 순수 토큰-채움(dataFill 없음)** 채택.
- 근거: 서식 43은 보전 체크된 선거비용을 자금원별로 **DB 집계**가 가능했으나, 서식 7의 수량(부수·매수)과 청구금액 세분류(점자인쇄비/한글인쇄료/운반비/수당)는 **acc_book에 그 입도로 존재하지 않는다**. 공식 양식 자체가 본질적으로 수기 작성 문서(xlsx 예시도 수기). → DB 집계는 불가/불신뢰.
- 효과: 기존 `/api/hwpx/generate`(generic 토큰 라우트) + `submission-forms` 페이지 `FormInputPanel`이 **추가 라우트/빌더 없이** 그대로 처리. 서식 43보다 단순.

### 2.2 입력 UI: 평면 필드(MVP) vs 표 그리드(개선)
- **결정: MVP는 평면 토큰 필드.** 수량·금액 셀(~25-30개)을 `fields()`로 평면 나열 → `FormInputPanel`이 자동 렌더. 추가 UI 작업 0.
- 개선(Phase 2): 수량/금액 표 전용 그리드 입력 컴포넌트로 UX 향상(행×열 격자). 별도 계획.

### 2.3 서식 ID 충돌 회피
- 기존 `id:"7"`은 **회계장부**(income-ledger). 본 양식은 다른 "서식 7"이므로 **별도 id**(예: `"7B"` 또는 `"burden-7"`)로 등록. `getFormDef`/UI 라벨에서 "점자형 선거공보 등 부담비용 지급청구서(서식 7)"로 명시.

## 3. 기능 요구사항

- **FR-01 양식 등록**: `form-fields.ts`에 서식 7 정의 추가(별도 id, orgScope: candidate, dataFill 없음).
- **FR-02 토큰 정의**: 머리(선거명·소속정당명·후보자명·선관위명), 수령계좌(수령_예금주/금융기관/계좌번호 재사용), 수량 표 셀, 청구금액 표 셀, 비고를 REG에 추가(대부분 `manual`, org 유래는 `organ` 컬럼).
- **FR-03 템플릿 토큰화**: 공식 RAG .hwpx의 해당 셀에 `{{토큰}}` 삽입 → `public/hwpx-templates/form-7b-fill.hwpx`. 제작 스크립트 `app/scripts/make-form-7b-fill.py`(기존 make-form-*-fill.py 패턴).
- **FR-04 prefill**: `use-hwpx-prefill`이 organ 유래 필드(후보자명·정당명 등) 자동 채움. 수량·금액·수령계좌는 사용자 입력.
- **FR-05 생성·다운로드**: 기존 `/api/hwpx/generate`로 `{ formId:"7B", values }` 전송 → 토큰 치환 .hwpx 다운로드. required 검증(선거명·후보자명·선관위명).
- **FR-06 노출**: candidate orgType에서만 제출서류 목록에 노출(`formsForOrgType`).
